# Kestrel seed nodes — example file.
#
# Rename to seeds.txt (next to the app) to use it, one node per line.
# Any address shape works — all of these are fine:
#
#   203.0.113.5
#   203.0.113.5:4444
#   http://203.0.113.5:4444
#   kestrel.example.org
#
# Got a VPS? Run a node on it (python -m kestrel.cli start --host 0.0.0.0),
# put its address in this file, and every app that ships with the file
# joins the network automatically.
#
# Better still: host a file like this on GitHub and put its Raw URL into
# SEED_LIST_URLS in kestrel/params.py — then you can add or remove public
# nodes any time without re-shipping the apps.
